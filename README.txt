# Mohana Mehndi & Makeup Studio - HTML/CSS/JS/Bootstrap

## Files
- index.html
- style.css
- script.js
- assets/ (AI-generated dummy bridal photos)

## Run
Open `index.html` in Chrome/Edge.

Bootstrap 5.3 and Bootstrap Icons are loaded from CDN, so internet is required for those CDN resources.

## Replace dummy photos
Put your real images inside `assets/` and keep the same filenames, or update the image paths in `index.html`.

## WhatsApp
The demo uses +91 81108 46493. Change the number in `index.html` and `script.js` to your actual WhatsApp number.

## Main features
- Responsive Bootstrap navbar
- Hero section
- Services
- About section
- Bridal packages
- Click-to-enlarge gallery
- Classes
- Booking form that opens WhatsApp
- Back-to-top button
- Mobile responsive layout
